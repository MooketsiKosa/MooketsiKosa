## Featured Projects

### 🌾 FarmForward: Farm Management Platform
Full-stack app with manager and worker dashboards, built with a team of 4. Express.js REST API across 8 route modules, JWT authentication, and a normalised 10-table PostgreSQL schema (query performance improved by 20%). API containerised with Docker.
`JavaScript` `Node.js` `Express.js` `PostgreSQL` `JWT` `Docker`

### 🚨 SentinelPath SA: Disaster Response Pathfinding
JavaFX tool for South African emergency scenarios (e.g. KZN floods) that converts aerial imagery into a risk-weighted graph and finds the safest rescue route. Across 100 randomised grids, A* explored 56% fewer nodes than Dijkstra while returning the same optimal-cost path every time.
`Java` `JavaFX` `Dijkstra` `A*`

### ♻️ Eco-Hub: University Second-Hand Marketplace
Marketplace with a 16-operation WCF/SOAP service layer, a 5-table SQL Server schema, role-based admin and customer portals, and an end-to-end invoicing pipeline.
`C#` `ASP.NET WebForms` `WCF/SOAP` `SQL Server`
